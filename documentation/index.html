Developer Guide

Prana Yoga & Meditation Studio HTML Template

A commercial-grade, multi-purpose HTML5/CSS3/ES6+ website template featuring 2 unique homepages, 10 yoga disciplines, a multi-step booking engine, member dashboard, and full admin management suite.

1. Quick Start & Local Preview

Prana is a 100% dependency-free vanilla HTML5/CSS3/ES6+ template. No Node.js build steps, Webpack, or compilers are required. You can preview it immediately using any local web server or by opening index.html in any modern browser.

# Run with Python Built-in Server: python -m http.server 8000 # Or with PHP: php -S localhost:8000 # Or using VS Code Live Server extension: Right click 'index.html' -> Open with Live Server

3. Strict Three-Color Rule

The entire template strictly adheres to exactly three core brand colors:

1. Black (#121614)
Primary text, contrast sections, dark mode surfaces.
2. White (#FFFFFF)
Clean light surfaces, cards, and text contrast.
3. Sage Green (#2F6A55)
Distinctive botanical brand accent color.

All borders, hover effects, and tags use CSS variables with opacity tints derived exclusively from these three colors in assets/css/style.css?v=2.2:

:root { --color-primary: #2F6A55; --color-primary-dark: #235040; --color-primary-light: #3e816a; --color-primary-subtle: rgba(47, 106, 85, 0.08); --color-black: #121614; --color-white: #ffffff; }

4. Strict Two-Font Rule

Typography strictly uses two Google Fonts:

  • Headings & Titles: Cormorant Garamond (Serif, elegant, grounding)
  • Body & Interface: Plus Jakarta Sans (Sans-serif, clean, ultra-readable)

6. Multi-Step Class Booking Workflow

The booking engine is implemented in assets/js/booking.js. Clicking any button with data-trigger="book-class" opens the interactive 6-step modal:

  1. Step 1: Select Class Discipline
  2. Step 2: Select Lead Teacher
  3. Step 3: Choose Session Date
  4. Step 4: Select Available Time Slot
  5. Step 5: Review Details & Membership Status
  6. Step 6: Confirmation with Reference ID & Calendar Export action

7. Member & Admin Dashboards

The template provides two distinct dashboard ecosystems sharing the same styling:

  • Member Portal (member-dashboard/): For registered students to book classes, view remaining credits, reschedule, cancel, manage memberships, and log wellness profiles.
  • Admin Suite (admin-dashboard/): For studio owners and managers to monitor live rosters, perform front-desk check-in, update timetables, add members, publish classes, and export reports.

8. Dark Mode & RTL Layout Engine

Both features are completely functional out-of-the-box and persist across page reloads via localStorage:

  • Dark Mode: Toggled via the moon/sun button. Reads OS system preferences on first visit.
  • RTL Mode: Toggled via the translate button. Flips layout, margins, and sidebars for Arabic and Hebrew without altering character directions.

9. Backend Integration Points

This static template is integration-ready. Connect with popular backend services:

  • Contact & Newsletter Forms: Add action="https://formspree.io/f/YOUR_FORM_ID" method="POST" to forms.
  • Stripe Checkout: Embed Stripe Elements or Stripe Checkout redirect in membership.html.
  • Google Maps: Replace the iframe placeholder with your Google Maps Embed API key in contact.html.
